# 拾光集（shiguang）

Qingci-Bot 安全插画发图 + 签到插件，由 AstrBot 插件「画境拾珍」（astrbot_plugin_get_px v3.5.1）移植。

## 功能

### 发图

| 命令 | 说明 | 预期效果 |
|------|------|----------|
| `/p [标签] [数量]` | 搜索并发送图片 | 按标签从 Lolicon 主源搜索图片并发送，可选 Pixiv 回退；数量默认 1（不超过 `max_count`）。`/p` 与 `/图` 等价 |
| 自然语言发图 | 发送「来 X 张/份/个 Y 图」 | `auto_trigger_enabled` 开启时触发，例如「来三张初音ミク图」「来一份图」。支持中文数字（一~十） |

发图功能自动执行：内容安全过滤（40+ 内置安全词 + 自定义安全词 + 作品 ID 黑名单）、多自然日去重（`dedupe_days`）、图片质量降级（大文件自动降档）、`forward_threshold` 以上合并转发（OneBot 11）。

### 签到

签到系统包含金币、好感度、连签、加持、成就、称号、生日、节假日、全局事件、主题商店、排行、备份导出/导入，以及 v1.1.0 起新增的补签卡/月卡、赛季排行与结算、打卡日历、幸运日、送花/转账/羁绊、收藏/画廊、每日一图订阅推送、LLM 签到助手、签到运势、定时提醒、管理审计（v1.2.0 起加入节日图集、签到速度榜、统计报表）等功能。

#### 基础命令

| 命令 | 说明 | 预期效果 |
|------|------|----------|
| `签到` | 纯文本签到 | 直接发送「签到」（`^(?!/)签到$`）触发每日签到，返回签到结果卡片（含金币/好感/连签/背景图） |
| `/签到` | 每日签到 | 执行每日签到，若签到卡渲染不可用自动降级纯文本 |
| `/签到帮助` | 签到指令帮助 | 发送签到帮助图片 |

#### 个人资料

| 命令 | 说明 | 预期效果 |
|------|------|----------|
| `/签到我的 状态` | 查看个人签到状态 | 显示当前金币、好感度、连签天数、累计签到等 |
| `/签到我的 生日查看` | 查看已设置的生日 | 显示当前绑定的生日日期 |
| `/签到我的 生日设置 MM-DD` | 设置生日 | 绑定生日至指定日期（如 `05-20`），生日当天签到获得额外奖励 |
| `/签到我的 生日清除` | 清除生日 | 移除已绑定的生日 |
| `/签到我的 成就` | 查看成就列表 | 展示已达成和未达成的成就（如连签 7 天、累计签到 30 天等） |
| `/签到我的 称号查看` | 查看已获得的称号 | 列出所有已解锁的称号 |
| `/签到我的 称号佩戴 [称号名]` | 佩戴称号 | 选择并佩戴一个称号，在签到结果中展示 |
| `/签到我的 日历 [YYYY-MM]` | 本月打卡日历 | 可视化当月已签/未签/连签（v1.1.0 新增，A3） |

| `/签到排行 月榜` | 本月签到排行 | 按月累计签到天数排名 |
| `/签到排行 连签` | 连签天数排行 | 按连续签到天数排名 |

| `/签到排行 赛季` | 赛季签到排行 | 按固定 30 天滚动赛季窗口排名，赛季结束自动结算 Top1/3/10 金币（v1.1.0 新增，A2） |

### WebUI 管理中心

插件管理页提供「拾光集管理中心」入口，包含：

- **群排行/趋势**：查看群内签到排名趋势（含赛季榜标签）
- **运营概览**：7 日活跃/周打卡率/月打卡率/用户与记录规模统计（v1.1.0 新增，D3）
- **每日一图群订阅管理**：启用/停用、标签、推送时间（v1.1.0 新增，C2）
- **群签到提醒管理**：启用/停用、提醒时间（v1.1.0 新增，D5）
- **赛季结算**：按群手动结算当前赛季奖励（v1.1.0 新增，A2）
- **统计报表下载**：近 7/30 天各群活跃与签到人次 CSV（v1.2.0 新增，E3）
- **审计日志**：管理操作留痕筛选与分页（v1.1.0 新增，E1）
- **成员数值编辑**：手动调整成员金币、好感度等数值
- **内容安全词管理**：添加/删除自定义安全词
- **作品黑名单管理**：按作品 ID 屏蔽图片，缩略图分批加载展示
- **签到备份导出/导入**：JSON 格式备份 & 恢复

## 安装

```bash
# 从插件市场安装：插件管理 → 插件市场 → 搜索「拾光集」（shiguang）
# 或手动克隆到 CE 实例的插件目录（instances/<name>/plugins/shiguang）后重启：
git clone https://gitee.com/luoqingciya/shiguang.git
# GitHub 备用镜像：git clone https://github.com/luoqingciya/shiguang.git
```

运行依赖：`aiohttp`（CE 主程序自带）。`Pillow`、`lunar-python`、`pixivpy-async`、`jinja2` 为可选——均为惰性导入，缺失时仅图片校验/农历节日/Pixiv 回退/签到卡渲染等功能按需降级，插件本身仍可正常加载。

## 配置

插件配置位于 `config.yaml` 的 `plugins.shiguang` 节（WebUI「插件管理 → 配置」可视化编辑）：

| 配置项 | 默认 | 说明 |
|---|---|---|
| `pixiv_refresh_token` | 空 | Pixiv 回退源 token（可选） |
| `lolicon_api_url` | `https://api.lolicon.app/setu/v2` | Lolicon 主源地址 |
| `max_count` | 5 | 单次最大发送数量 |
| `dedupe_days` | 1 | 图片按自然日去重天数（0=关闭） |
| `request_timeout` | 30 | 下载超时（秒） |
| `image_quality` | `original` | 图片质量（original/large/medium） |
| `forward_threshold` | 1 | 超过该数量用合并转发（仅 OneBot 11） |
| `auto_trigger_enabled` | false | 自然语言触发开关 |
| `checkin_enabled` | true | 签到功能开关 |
| `rate_limit_seconds` | 3 | 请求频率限制（秒） |

完整配置项见 `ShiguangPlugin.Config`（`__init__.py` 内 pydantic 模型，WebUI 表单 schema 来源；原 `_conf_schema.json` 已删除）。

## 说明

- **触发语义**：Qingci 群聊默认 `trigger_mode: at`，命令需 @bot；纯文本「签到」规则为 `^(?!/)签到$` 不受影响
- **签到卡渲染**：HTML 签到卡依赖框架 HTML 渲染服务（Playwright，`qingci-bot-ce[render]`），
  渲染不可用时自动降级纯文本签到
- **数据**：签到 SQLite（`data_root()/plugins/shiguang/checkin.sqlite3`）与发图去重索引与主库隔离，
  插件卸载不删除数据（备份前请谨慎）
